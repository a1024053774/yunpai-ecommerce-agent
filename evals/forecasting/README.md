# 销售需求预测合成评测

本目录用确定性的虚拟销售序列验证预测模型和选择逻辑。它覆盖稳定、趋势、周季节、趋势叠加季节、间歇、块状、波动、零需求、冷启动和结构变化，并把缺失日期、缺货截断与缺少促销日历作为独立数据质量风险。

评测使用滚动窗口，训练截止日必须早于预测起始日。普通场景必须同时满足场景级 WAPE、绝对偏差和需求类型预期；风险场景必须显式返回 `degraded` 及对应质量标记，不能靠完成预测流程冒充准确。

间歇与块状需求无法从历史序列确定下一次非零销售落在哪一天，Croston/TSB 只估计周期平均需求。因此这两类场景保留逐日 WAPE 的宽上限，同时以更严格的周期总量偏差作为主要门禁；全零预测会因总量偏差超限而失败。

运行：

```bash
python -m evals.forecasting.run
```

所有数据均为合成数据，`production_claim=false`。本评测不证明真实订单口径、促销日历、缺货修正、库存预测、补货建议或生产可用性。
