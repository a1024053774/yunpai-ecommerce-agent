退换货细则
  退换货时限    退换货原因    处理流程    注意事项 
 1、退换货时限 
 自实际收到商品之日起7天内可退货，15天可换货。 
 2、退换货原因 
 1 ) 商品质量问题。 
 2 ) 在商品（含附件）完好前提下可享受7天无理由退货。 
 3 ) 注意事项中约定不适合退换的商品除外。 
 3、处理流程 
 1 ) 首先确认产品是非人为损坏。 
 2 ) 将附件、说明书、发票、购物凭证、包装、商品及捆绑的赠品一并返回我司办理退换货手续。 
 4、注意事项 
 1 ) 因个人原因造成的商品损坏（如自行修改尺寸，洗涤，皮具打油，刺绣，长时间穿着等），不予退货。 
 2 ) 出于安全和卫生考虑，贴身用品如内衣裤，袜子，泳衣类商品和定制眼镜不予退换货，经权威部门检测商品存在质量问题者除外。 
 3 ) 如商品吊牌、包装及商品附件（如纽扣等）标签破损或丢失，不予办理退换货。 
 4 ) 海外代购商品属特殊商品，不支持7天无理由退货。 
 5 ) 包装含防伪码的商品防伪码一经刮开不予退换货。
