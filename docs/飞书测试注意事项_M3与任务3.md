## 📋 你要测什么（一句话）

M3 交付了**知识图谱 + 检索 API + Wiki 知识库前台**，你按下面步骤测，重点验证"**词条能看、搜索能中、编辑能生效**"。

## 🎯 3 个核心验收点

1. **控制台「知识库」模块**：登录后左侧导航点「知识库」→ 看到词条列表（370 条左右）→ 点开详情看到"当前结论/属性/演化历史"
2. **搜索**：顶部搜「保修」→ 命中保修政策（需 Neo4j 运行）
3. **编辑生效**：编辑一条 FAQ → 审批 → Wiki 详情立即显示新结论（这是本任务核心）

## ⚠️ 测试前必读（最容易踩的坑）

| # | 注意事项 | 说明 |
|---|---|---|
| 1 | **必须加载 .env 再启动** | 项目不自动读 .env，启动命令见总文档 §2.3 |
| 2 | **端口 8000 必须空闲** | 被占会报 `data directory is in use`（DisasterRecoveryError） |
| 3 | **Neo4j 可选** | 不启动也能测列表/详情/编辑；只影响搜索和图谱（有提示） |
| 4 | **登录信息** | 管理员 ID `local-admin` / 密钥 = 你 .env 里的 `ADMIN_API_KEY` |
| 5 | **编辑只对 Q&A 类生效** | FAQ/话术/政策/规则可编辑；商品/SKU/品类/属性是只读资产 |
| 6 | **图谱是静态快照** | 编辑后图谱/搜索可能滞后，需重跑 export_graph.py |
| 7 | **行必须带 tenant_id** | 生命周期 API 只管理带租户的行（`/v1/admin/knowledge`） |
