## 二、测试环境准备（约 40 分钟）

### 1. Python 环境

```bash
python3.11 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
python -m pip install -e ".[dev]"
```

### 2. 生成 .env（关键！项目不自动读 .env）

```bash
# 从模板复制，替换 3 个密钥
cp .env.example .env
# 编辑 .env：替换 ADMIN_API_KEY / BOOTSTRAP_CLIENT_KEY / SUBJECT_HASH_KEY
# 本地测试建议 MODEL_MOCK_MODE=true（不依赖外部模型）
```

### 3. 启动服务（必须先加载 .env）

```bash
# Windows Git Bash
cd <项目根目录>
export $(grep -v '^#' .env | grep -v '^$' | xargs)
.venv/Scripts/python.exe -c "
from ecommerce_agent.api import create_app
import uvicorn
uvicorn.run(create_app(), host='127.0.0.1', port=8000, log_level='warning')"
```

> ⚠️ **端口占用**：启动前确认 8000 空闲（`netstat -ano | grep :8000`）。端口被占会报 `DisasterRecoveryError: data directory is in use`。

### 4. Neo4j（可选，供搜索/图谱用）

```bash
# 本机已装：D:\neo4j-community-2026.04.0
D:\neo4j-community-2026.04.0\bin\neo4j.bat console
# 账号：neo4j / ${NEO4J_PASSWORD:-change-me}
# 重建数据：knowledge_graph_output/04_import/ 的 3 个 Cypher（约束→节点→关系）
# 期望：219 节点 / 241 关系
```

> **Neo4j 不启动**：「知识库」模块的列表/详情/统计仍可用（走运行时表+资产层），仅搜索和图谱不可用（前端有提示）。

### 5. 登录控制台

- 地址：`http://127.0.0.1:8000/admin`
- 左侧导航 → **「知识库」**（第 17 个模块）
- 管理员：`local-admin` / 你 .env 里的 `ADMIN_API_KEY`

### 测试 3：控制台手工浏览（核心验收）

1. 打开 `http://127.0.0.1:8000/admin` → 登录 → 点「知识库」
2. **KPI 概览**：词条总数 / 运行时可编辑数 / 资产层只读数
3. **左栏类型导航**：点「行业规则」→ 列表只剩 rule；点「FAQ」→ 只剩 faq
4. **词条详情**：点任意一行 → 当前结论 + 属性表 + 演化历史时间线
5. **搜索**：顶部搜「保修」→ 列表切换为图谱搜索结果（需 Neo4j）
6. **图谱视图**：点「在新标签打开图谱」→ D3 力导向图可浏览，有滞后提示

### 测试 4：编辑生效闭环（任务3 核心能力）

```bash
# 走生命周期：revise → evaluate → approve
curl -X POST http://127.0.0.1:8000/v1/admin/knowledge/FAQ-XXX/versions \
  -H "Content-Type: application/json" -H "X-Admin-Id: local-admin" -H "X-Admin-Key: <ADMIN_API_KEY>" \
  -d '{"expected_record_version":1,"answer":"新结论"}'
# 拿返回的 candidate id + record_version → evaluate → approve

# 然后查 Wiki 详情，应显示新结论
curl http://127.0.0.1:8000/v1/wiki/items/FAQ-XXX -H "X-Admin-Id: local-admin" -H "X-Admin-Key: <ADMIN_API_KEY>"
# 期望: compiled_truth = 新结论，timeline 含 revised
```

> **注意**：生命周期只管理 Q&A 类（FAQ/话术/政策/规则）且行必须带 tenant_id。实体类（商品/SKU/品类/属性）只读不可编辑——设计边界。

## 六、已知边界（测试人必须知道）

| 边界 | 说明 |
|---|---|
| 数据三层 | 资产层 `02_clean/` 严格只读；运行时表可编辑（`/v1/admin/knowledge`）；Neo4j 图谱需重建 |

| 编辑限 Q&A 类 | 且行必须带 tenant_id |
