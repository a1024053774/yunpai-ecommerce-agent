# 需求预测趋势图设计

## 目标

以一张连续趋势图替代历史预测对比表和未来预测表，让经营人员直观看到历史销量、模型历史表现和未来销量预期。

## 图表口径

图表以日期为横轴、销售需求量为纵轴，连续展示三个互斥时间段的数据：

| 数据 | 时间范围 | 样式 | 含义 |
| --- | --- | --- | --- |
| 实际销售需求 | 最近 90 个已观测日 | 深青色实线 | 已实际发生的可履约日需求。 |
| 历史预测销售需求 | 与实际回测重叠的日期 | 绿色虚线 | 模型在该日期发生前给出的单点预测，用于和实际销量比较。 |
| 未来预测销售需求 | 预测窗口内的日期 | 橙色虚线 | 当前预测运行的 `p50` 单点预测。 |

历史与未来预测都是单点预测。历史回测没有持久化当时的 `p80`/`p95`，因此不事后伪造历史区间；本次也不在未来绘制区间带，以保持当前业务界面简洁。

## 页面结构

- 将“已观测需求与历史预测对比”和“未来每日需求预测”两个表格替换为一个“销售需求趋势”卡片。
- 卡片顶部显示三条线的图例，使用文字和线型共同区分，不能只依赖颜色。
- SVG 图的横轴为日期、纵轴为销量；默认包含最近 90 天历史和本次未来窗口。
- 悬停或触碰数据点时显示日期、实际销量、历史预测或未来预测的具体值；无数据点时不显示无意义提示。
- 小屏幕保持可读：图表最小绘图宽度固定，外层横向滚动；不压缩文字或重叠坐标轴。

## 实现边界

- 不新增图表第三方依赖；在 `docs/admin-console.html` 中以原生 SVG 和 JavaScript 渲染。
- 复用现有需求事实、回测和预测运行接口，不新增 API、Schema 或持久化字段。
- 图表内的未来线仅读取 `forecast_points[].p50`；接口继续保留 `p80` 和 `p95`，但本次不在后台主界面展示。
- 不创建库存预测、库存快照、补货订单或库存风险计算。

## 验收

- 页面不再包含 `backtestRows`、`forecastRows`、P80 或 P95 预测表头。
- 页面包含趋势图容器、三条中文图例以及 SVG 渲染函数。
- 传入历史需求、回测与未来 `p50` 时，图表渲染三种线型；未来线不读取 `p80` 或 `p95`。
- 空数据或预测读取失败时，图表显示明确空状态，不抛出前端错误。
