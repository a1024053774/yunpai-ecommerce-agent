# 三年虚拟销售预测评估设计

## 目标

提供一条可重复运行的本地验收路径：生成三年虚拟日销售订单，使用现有预测引擎保存预测运行和滚动回测，并在后台以中文对比已观测真实需求与历史预测。

## 范围

- 虚拟数据固定标记为样例，不作为真实平台效果声明。
- 使用最近 90 天的滚动回测窗口展示已观测实际需求与预测值。
- 后台预测区只需要店铺和 SKU；不显示仓库、库存快照、补货风险或补货计划。
- 预测方法、模型结论、需求类型和数据质量使用中文展示；接口枚举保持原样。

## 数据流

虚拟订单 -> demand-v1 日需求事实 -> 已持久化 forecast run/backtests/points -> 后台预测方法摘要、历史回测对比和未来预测。

预测运行使用已有 Schema 29 持久化表，不新增迁移、不创建采购单、不更新库存。
