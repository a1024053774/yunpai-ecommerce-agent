# 云湃电商一体机 Agent · 模块功能说明

> 面向读者：电商店铺经营者 / 运营 / 客服主管
> 版本基线：0.23.0 运营控制台版 · 2026-08-09

---

## 0. 产品是什么

一台放在店里的"电商经营 AI 一体机"：AI 负责接待顾客、分析生意、写文案、盯竞品；系统负责保证每一步**有据可查、有人把关、出错可回滚**——不乱承诺、不乱改价、不乱退款、不乱发内容。

### 0.1 界面入口

整套系统只有两个页面：

| 页面             | 地址                                    | 给谁用                 |
| ---------------- | --------------------------------------- | ---------------------- |
| 经营与客服控制台 | `http://127.0.0.1:8080/admin`         | 店主 / 运营 / 客服主管 |
| 顾客对话测试页   | `http://127.0.0.1:8080/customer-test` | 扮演顾客，体验 AI 客服 |

控制台左侧共 16 个板块，本文按业务主题分成 8 章介绍。

## 2. 智能客服

### 2.1 顾客视角：AI 客服问答

**对应页面：`/customer-test` 独立顾客测试页**

像顾客一样发消息，AI 秒回；回答全部基于店铺知识库证据，答不了、风险高就自动转人工，不瞎编。

值得展示的点：

- 问商品参数 / 价格 / 物流政策，AI 直接给答案
- 问退款、投诉等高风险问题，AI 建人工任务而不是乱承诺
- 内置 156 条电商问法覆盖面（页面右侧有测试案例可直接点）

### 2.2 商家视角：智能客服工作台

**对应板块：智能客服**

AI 接了多少、答了什么、为什么这么答，全部可回放；接不住的进人工队列，按技能和容量自动派单。

核心功能：

- 会话回放：点开任意一条会话，能看到每句回答的意图判断、风险等级、引用证据和决策轨迹
- 人工接管队列：AI 转出的任务，支持优先级、认领、SLA、转派、升级
- 坐席调度与排班：坐席在线状态、周期批量排班、队列容量
- 自动派单：按队列策略持久自动分配，有告警提示

### 2.3 渠道视角：渠道接待工作台

**对应板块：渠道接待**

接入店铺渠道（淘宝虚拟接口）后，AI 按"影子 / 辅助 / 协同 / 自动"四档模式上岗；人工可随时暂停、接管、改写，每条外发消息都先进"可靠发送箱"再投递，不丢消息不重发。

核心功能：

- AI / 人工 / 已暂停三种会话归属，一键切换，暂停后自动发送会被二次拦截
- 人工改写 AI 草稿，结构化对比差异后再发送
- 发送队列与人工核对：发送失败、不确定态、死信都留痕，可人工确认后重排

## 3. 商品与库存

**对应板块：商品库存**

## 4. 订单与售后

**对应板块：订单售后**

订单、物流、售后单统一聚合，买家信息自动脱敏；客服看得到状态、办得了流转，但系统绝不自己执行退款。

核心功能：

- 订单事实：金额、订单状态、支付状态、物流、售后、版本历史
- 客服任务联动：从订单直接建人工任务（虚拟验收 / 隔离评测任务分开管理）

## 5. 竞品分析

**对应板块：竞品分析**

系统自动找同款、比价格、盯降价，触发告警提醒人来决策——它提供证据和建议，改不改价永远由你拍板。

核心功能：

- 同款匹配：按品牌、型号、条码、关键属性给出可解释评分，运营人工裁决是不是同款
- 监控策略：按店铺 / SKU 设低价、降价、新鲜度阈值
- 持久告警：触发后可确认、解决，有新证据自动复发重开
- 竞品明细 + 价格趋势：价差、位置、聚合口碑（不存原始评论和评论者）

## 6. 营销与文案

### 6.1 运营辅助与文案生成

**对应板块：运营辅助**

把日常运营数据（CSV / JSON / 手工表单）丢进来，AI 生成多风格候选文案和趋势解读；发不发、改不改，人工审核说了算。

核心功能：

- 数据导入：CSV / JSON 文件（最多 2000 行）或表单录入，同日同渠道自动版本化
- 多风格候选文案：一次生成多条，供人工挑选修改
- 数据解读 + 趋势与优化建议（仅建议，不执行）

### 6.2 营销投放诊断

**对应板块：营销投放**

活动日指标（花费、归因收入、ROAS、点击曝光）自动归集，AI 给可解释的投放诊断；不碰竞价、不动预算、不直接发内容。

- 活动日指标表 + 投放诊断（仅建议）
- 内容草稿事实校验：文案里的主张（价格、权益、参数）先过事实校验，再由人工决定发布

## 7. 利润与对账

**对应板块：利润对账**

费用归集、平台结算单、对账差异一屏管理——差多少钱、差在哪一单看得见；它是经营估算助手，不是财务总账，更不碰资金。

核心功能：

- 费用归集：按类别 / 来源 / 版本导入费用
- 结算单：销售额、退款、平台费、报告结算额
- 对账差异任务：预期结算 vs 报告结算，差异生成任务由人工处置

## 8. 让 AI 可控可信

这一章的 6 个板块回答同一个问题：**凭什么敢让 AI 直接面对顾客？**

### 8.1 知识与 SOP（对应板块：知识与 SOP）

- 知识分五层：平台 / 行业 / 店铺 / 商品 / 进化知识，按店铺、SKU 圈定范围
- 每条知识不可变版本化：评测 → 批准 → 上线 → 可回滚，AI 只能引用"已批准"的版本
- SOP 流程引擎：把退换货这类流程写成固定步骤，中途要人审批的一步都不会跳过
- 受控自进化：顾客负反馈会催生新话术候选，但必须过安全门禁 + 管理员批准才上线

【截图 08a：知识版本表 + SOP 定义列表】→ `image/模块功能说明/1786340443657.png`

![知识与 SOP](./image/模块功能说明/1786340443657.png)

### 8.2 质检与 VOC（对应板块：质检 VOC）

- 代码化质检规则：证据缺失、漏转人工、敏感信息、高风险回复自动查出来
- 问题分布 + 严重度看板；质检结果必须人工确认或驳回，不自动改线上规则

- 评测结果直接作为"能不能上线"的审批证据

- 影子 / 仅提示 / 人机协同 / 白名单自动，四档逐步放量
- 运行熔断：严重回答或投递失败自动暂停策略，可回滚

## 10. 边界声明

1. 不执行退款、赔付、资金操作；
2. 不自动改价、不自动调预算、不自动出价；
3. 不自动发布商品、文案和营销内容，发布必须人工审核；
4. 不伪装真实平台授权，虚拟淘宝接口只在本机演练；
5. AI 没有权限放行权：工具未注册、参数缺失、规则拒绝，模型说什么都绕不过去；
6. 买家隐私全程脱敏，不保存评论者、订单标识与原始评论。

## 附录. 名词速查

| 名词          | 大白话                                           |
| ------------- | ------------------------------------------------ |
| 意图          | 顾客这句话想干嘛（问价 / 催发货 / 要退款……）   |
| 证据          | AI 回答时引用的知识库条目，条条可溯源            |
| 转人工 / 接管 | AI 判断接不住，建任务交给真人客服                |
| SOP           | 固化的标准流程，例如退换货处理步骤               |
| 灰度 / 分流   | 新策略先给一小部分顾客用，稳了再放量             |
| 回放          | 用历史会话在隔离环境重跑一遍新策略，上线前先考试 |
| 熔断          | 线上出严重问题自动暂停 AI 策略                   |
| 脱敏          | 手机号、地址等隐私自动打码后才入库               |
| VOC           | 顾客之声，从会话里聚合出的问题反馈               |
